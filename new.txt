git init - инициализация локального репозитория, запуская в начала один раз при отсутсвии папки .git в текущей деректории.
git config --global user.name "alexgrebell"
git config --global user.email vorotaryok@gmail.com
git config --global core.editor "code --wait"
git status - показывает текущий статус git репозитория. Основные состояния. Красные файлы - это изменёные файлы не добавленые в очередь на комит. Соответственно зелённые это файлы поставленные в очередь на комит. отсутсвие файлов - изменений в репозитории нет.
git add <param> - добавить файлы в очередь на комит. Param - может быть названием файла или деректории полностью. "." - добовляет все измененные файлы в очередь.
git commit [-m "сообщение"] - формирует из очереди файлы в точку сохранения репозитория только локально.
git add всегда придшествует git commit если в репозитории были изменения.
git push - отправляет точки сохранения репозитория (комиты) на сервер если они до этого не были отправлены.
git pull - получает сохранёные комиты с сервера.

        Если на сервере были комиты с другого места, то обязательно перед началом работы git push, чтобы узнать о возможных изменениях.

git fetch - проверяет текущее состояние репозитория (инфо).
git push -force - всё перезаписать в репозитории.
git branch - посмотри в учебнике.
git checkout - посмотри в учебнике.
git merge - объеденение данных (веток) в одну. Дополнительно снова в учебнике.
git diff - показывает разницу между двумя (для vim).
git reset - три варианта (почитай в учебнике).
git revert - почитай в учебнике.
git remote - добавляет ссылку на репозиторий где всё хронится.
